ما هو المتغير العشوائي؟
Random Variable (RV)

المتغير العشوائي هو دالة تُعيّن قيمة عددية لكل نتيجة في فضاء العينة. يُرمز له بحروف كبيرة مثل X أو Y.

التعريف الرسمي
\( X : S \rightarrow \mathbb{R} \)
📌 لماذا نستخدمه؟ يُحوّل النتائج غير الرقمية (مثل: وجوه/أرقام، أحمر/أزرق، فصيلة الدم) إلى أرقام يمكن التعامل معها رياضياً وإحصائياً.

أنواع المتغيرات العشوائية

📊 المتقطع (Discrete)

يأخذ قيماً قابلة للعد (محدودة أو غير محدودة). مثال: عدد الوجوه في رمي عملة، نتيجة النرد.

📈 المستمر (Continuous)

يأخذ أي قيمة في فترة مستمرة. مثال: اختيار رقم حقيقي عشوائي من [1,10]، الطول، الوزن.

🔀 المختلط (Mixed)

يجمع بين المتقطع والمستمر. مثال: رمي عملة، إذا وجوه → رقم حقيقي، إذا أرقام → صفر.

مثال: رمي 3 عملات (HHH ، HHT ، ...)

دالة الكتلة الاحتمالية
Probability Mass Function — pmf

تُستخدم مع المتغيرات العشوائية المتقطعة فقط. تعطي احتمال أن يساوي المتغير العشوائي قيمة بعينها.

التعريف
\( p_X(k) = P\{X = k\} \)

خصائص الـ pmf

1
عدم السالبية
\( \forall k,\quad p_X(k) \geq 0 \)
2
مجموع كل الاحتمالات = 1
\( \sum_k p_X(k) = P\{S\} = 1 \)
3
احتمال حدث A
\( P\{A\} = \sum_{k \in A} p_X(k) \)
📌 متى تستخدمه لحساب احتمال أي حدث: جمع كتل الاحتمال لكل قيم k التي تنتمي لهذا الحدث.

أمثلة على قراءة الـ pmf

P{X ≤ 3} = P{X ∈ {1,2}} = p_X(1) + p_X(2)
P{2 ≤ X ≤ 4} = p_X(2) + p_X(4)
P{X > 4} = p_X(6.5) + p_X(7)
P{|X−4| > 1} = p_X(1) + p_X(2) + p_X(6.5) + p_X(7)
P{|X−4| = 3} = p_X(1) + p_X(7)
⚠️ ملاحظة

الـ pmf غير مفيدة للمتغيرات المستمرة لأن P{X = أي نقطة بعينها} = 0 دائماً.

رسم pmf للمتغير Y₁ (ترقيم رمي 3 عملات)

p_Y₁(k) — كل قيمة احتمالها 1/8
p_Y₂(k) — عدد الأرقام في 3 رميات

دالة التوزيع التراكمي
Cumulative Distribution Function — CDF

تُستخدم مع جميع أنواع المتغيرات العشوائية (متقطعة، مستمرة، مختلطة). تعطي احتمال أن يكون المتغير أقل من أو يساوي قيمة x.

التعريف
\( F_X(x) = P\{X \leq x\} = \sum_{k \leq x} p_X(k) \quad \text{(للمتقطع)} \)

خصائص الـ CDF

1
الحدود
\( \lim_{x \to -\infty} F_X(x) = 0 \qquad \lim_{x \to +\infty} F_X(x) = 1 \)
2
متصاعدة غير تنازلية
\( a < b \implies F_X(a) \leq F_X(b) \)
3
مستمرة من اليمين
\( F_X(a) = \lim_{x \to a^+} F_X(x) \triangleq F_X(a^+) \)
4
احتمال فترة
\( P\{a < X \leq b\} = F_X(b) - F_X(a) \)
5
احتمال نقطة بعينها
\( P\{X = a\} = F_X(a) - F_X(a^-) \)
📌 القفزات في الـ CDF في المتغير المتقطع، الـ CDF تقفز عند كل قيمة لها كتلة احتمال. حجم القفزة = قيمة الـ pmf عند تلك النقطة.
pmf وCDF للمتغير Y₂ (عدد الأرقام في 3 رميات)
💡 كيف تقرأ CDF المتقطع

الـ CDF للمتغير المتقطع هي دالة سلمية: تبقى ثابتة بين نقاط القيم، ثم تقفز فجأة عند كل قيمة يأخذها المتغير. تأكد من النقاط المفتوحة والمغلقة في الرسم (مستمرة من اليمين).

دالة كثافة الاحتمال
Probability Density Function — PDF

تُستخدم مع المتغيرات المستمرة فقط. هي مشتقة الـ CDF، وتعطي كثافة الاحتمال حول كل نقطة — ليست احتمالاً مباشراً.

التعريف — مشتقة CDF
\( f_X(x) \triangleq \dfrac{d}{dx} F_X(x) \)
العلاقة العكسية — CDF من PDF
\( F_X(x) = \int_{-\infty}^{x} f_X(t)\, dt \)
احتمال فترة
\( P\{a < X \leq b\} = F_X(b) - F_X(a) = \int_a^b f_X(x)\, dx \)

خصائص الـ PDF

1
عدم السالبية
\( \forall x,\quad f_X(x) \geq 0 \)
2
التطبيع — المساحة الكلية = 1
\( \int_{-\infty}^{+\infty} f_X(x)\, dx = 1 \)
⚠️ تنبيه مهم جداً

الـ PDF ليست احتمالاً! قيمة f_X(x) قد تتجاوز 1. الاحتمال يُحسب فقط من المساحة تحت المنحنى (التكامل)، وليس من ارتفاع النقطة.
لذلك: P{X = نقطة بعينها} = 0 دائماً للمتغير المستمر.

مثال: X موزّع بشكل منتظم على [1, 10]

CDF

F_X(x) = 0   (x < 1)
F_X(x) = (x−1)/9   (1 ≤ x ≤ 10)
F_X(x) = 1   (x > 10)

PDF

f_X(x) = 0   (x < 1)
f_X(x) = 1/9   (1 < x < 10)
f_X(x) = 0   (x > 10)
CDF و PDF لتوزيع منتظم على [1,10]

المتغير العشوائي المختلط
Mixed Type Random Variable

يجمع بين خصائص المتقطع والمستمر. يظهر في الـ CDF كمزيج من قفزات (الجزء المتقطع) ومناطق مستمرة (الجزء المستمر). أما الـ PDF فيتضمن دوال دلتا δ عند نقاط القفز.

مثال كامل: رمي عملة + اختيار رقم

أرمي عملة عادلة. إذا وجوه (H) → أختار رقماً عشوائياً من [1,6]. إذا أرقام (T) → أختار الصفر.
ليكن Y هو الرقم المختار. جد توزيع Y.
1
عند y = 0:
F_Y(0) = P{Y≤0|H}·P{H} + P{Y≤0|T}·P{T} = 0·(1/2) + 1·(1/2) = 1/2
2
لـ 0 < y < 1: لا تزيد الـ CDF (لا توجد كتلة هنا)
F_Y(y) = 1/2
3
لـ 1 ≤ y ≤ 6:
F_Y(y) = P{Y≤y|H}·(1/2) + P{Y≤y|T}·(1/2) = (y−1)/(6−1)·(1/2) + 1·(1/2) = (y+4)/10
4
لـ y > 6:
F_Y(y) = 1
CDF المختلطة
\( F_Y(y) = \begin{cases} 0 & y < 0 \\ 1/2 & 0 \leq y \leq 1 \\ (y+4)/10 & 1 < y \leq 6 \\ 1 & y > 6 \end{cases} \)
PDF المختلطة (تتضمن دلتا)
\( f_Y(y) = \dfrac{1}{2}\delta(y) + \begin{cases} 1/10 & 1 \leq y \leq 6 \\ 0 & \text{otherwise} \end{cases} \)
💡 دالة دلتا δ(y)

دالة دلتا ديراك δ(y) تمثل الكتلة الاحتمالية المركّزة في نقطة واحدة. هنا المعامل 1/2 يعني أن احتمال Y = 0 هو 1/2. في الرسم تظهر كسهم (spike) عمودي.

مسألة 1 — الجرّة والـ PMF والـ CDF
متغير عشوائي متقطع

نص المسألة

جرّة تحتوي 3 زرقاء + 5 بيضاء + 2 حمراء. نسحب كرة عشوائياً.
عرّف متغيراً عشوائياً X. ارسم pmf وcdf. احسب P{أزرق} من pmf. احسب P{ليس أحمر} من cdf.

1
تعريف المتغير: X = 1 (أزرق)، X = 2 (أبيض)، X = 3 (أحمر)
إجمالي = 10 كرات
2
الـ PMF:
p_X(1) = 3/10,   p_X(2) = 5/10,   p_X(3) = 2/10
التحقق: 3/10 + 5/10 + 2/10 = 1 ✓
3
الـ CDF:
F_X(x) = 0     x < 1
F_X(x) = 3/10   1 ≤ x < 2
F_X(x) = 8/10   2 ≤ x < 3
F_X(x) = 1      x ≥ 3
4
P{أزرق} من PMF:
P{أزرق} = p_X(1) = 3/10
5
P{ليس أحمر} من CDF: P{X < 3} = P{X ≤ 2} = F_X(2)
P{ليس أحمر} = F_X(2) = 8/10 = 0.8
ملاحظة: P{ليس أحمر} = 1 − P{أحمر} = 1 − 2/10 = 8/10 ✓

مسألة 2 — إيجاد CDF من PMF معطاة
رسم CDF

نص المسألة

المتغير X: P{X=1} = P{X=3} = P{X=2}/2 وP{X=x}=0 لغير ذلك.
ارسم CDF.

1
ليكن P{X=1} = P{X=3} = c، إذن P{X=2} = 2c
c + 2c + c = 1 → 4c = 1 → c = 1/4
2
الـ PMF:
p(1) = 1/4,   p(2) = 2/4 = 1/2,   p(3) = 1/4
3
الـ CDF (سلم):
F(x) = 0    x < 1
F(x) = 0.25   1 ≤ x < 2
F(x) = 0.75   2 ≤ x < 3
F(x) = 1     x ≥ 3
الجواب: CDF ذات ثلاث قفزات: عند 1 بمقدار 0.25، عند 2 بمقدار 0.5، عند 3 بمقدار 0.25

مسألة 3 — CDF مختلطة ومطلوب احتمالات
قراءة CDF وإيجاد PDF

نص المسألة

F_X(x) = { 0 (x<0), (x+2)/4 (0≤x<1), 3/4 (1≤x<2), 1 (x≥2) }

(a) أحسب: P{X=0}, P{X≤0}, P{X≥0}, P{1/2<X<3/2}, P{X=1}, P{X>1}, P{X=2}, P{1≤X<2}
(b) أوجد pdf.

تحليل
هذا متغير مختلط: مستمر في [0,1) وقفزة عند x=1 وقفزة عند x=2.
F(0⁻) = 0  |  F(0) = 2/4 = 1/2  ← قفزة عند 0 بمقدار 1/2
F(1⁻) = (1+2)/4 = 3/4  |  F(1) = 3/4  ← لا قفزة عند 1
F(2⁻) = 3/4  |  F(2) = 1  ← قفزة عند 2 بمقدار 1/4
a
P{X=0} = F(0) − F(0⁻) = 1/2 − 0 = 1/2
P{X≤0} = F(0) = 1/2
P{X≥0} = 1 − F(0⁻) = 1 − 0 = 1
P{1/2 < X < 3/2} = F(3/2) − F(1/2) = 3/4 − (1/2+2)/4 = 3/4 − 5/8 = 1/8
P{X=1} = F(1) − F(1⁻) = 3/4 − 3/4 = 0
P{X>1} = 1 − F(1) = 1 − 3/4 = 1/4
P{X=2} = F(2) − F(2⁻) = 1 − 3/4 = 1/4
P{1≤X<2} = F(2⁻) − F(1⁻) = 3/4 − 3/4 = 0
b
الـ PDF = مشتقة الـ CDF:
f_X(x) = (1/2)δ(x) + (1/4) على [0,1) + (1/4)δ(x−2)
في [0,1): المشتقة = d/dx · (x+2)/4 = 1/4
تفسير: عند x=0 هناك كتلة 1/2 (متقطع)، وفي الفترة [0,1) الكثافة = 1/4 (مستمر)، وعند x=2 كتلة 1/4 (متقطع).

مسألة 4 — إيجاد ثابت من شرط التطبيع
خاصية ∫f(x)dx = 1

نص المسألة

f_X(x) = { 2a−2x (0<x<a), (2/3)(x−a) (a≤x<4a), 0 otherwise }
(a) Find a.   (b) Find P{1/2 < X ≤ 3/2}.

a
شرط التطبيع: ∫f(x)dx = 1
∫₀ᵃ (2a−2x)dx + ∫ₐ⁴ᵃ (2/3)(x−a)dx = 1
الجزء الأول:
∫₀ᵃ (2a−2x)dx = [2ax − x²]₀ᵃ = 2a² − a² = a²
الجزء الثاني:
∫ₐ⁴ᵃ (2/3)(x−a)dx = (2/3)[(x−a)²/2]ₐ⁴ᵃ = (2/3)·(3a)²/2 = (2/3)·9a²/2 = 3a²
إذاً:
a² + 3a² = 1 → 4a² = 1 → a = 1/2
b
بعد a = 1/2: النطاقات هي (0, 1/2) و[1/2, 2) و0 خلاف ذلك
P{1/2 < X ≤ 3/2} = ∫_{1/2}^{3/2} f(x)dx
ملاحظة: في [1/2, 2) الدالة = (2/3)(x − 1/2)
= ∫_{1/2}^{3/2} (2/3)(x − 1/2)dx = (2/3)·[(x−1/2)²/2]_{1/2}^{3/2}
= (2/3)·[(1)²/2 − 0] = (2/3)·(1/2) = 1/3
الجواب: a = 1/2   و   P{1/2 < X ≤ 3/2} = 1/3
